Raspberry Pi 4 Model B

🍓 ¿Qué es?

Es un ordenador de placa única (SBC) de alto rendimiento desarrollado por la Fundación Raspberry Pi. Del tamaño de una tarjeta de crédito, ofrece rendimiento de nivel de PC de escritorio manteniendo un bajo costo y un consumo de energía mínimo.

🚀 ¿Qué permite hacer?

  • Crear consolas de videojuegos retro (emuladores).
  • Desarrollar proyectos de robótica, IoT y automatización.
  • Montar servidores web, NAS locales y centros multimedia 4K.
  • Aprender programación y electrónica desde cero.

⚙️ Especificaciones Técnicas Detalladas

• Procesador: Broadcom BCM2711, Quad-core Cortex-A72 (ARM v8) de 64 bits a 1.5 GHz.

• Memoria RAM: Opciones de 1GB, 2GB, 4GB o 8GB LPDDR4-3200 SDRAM.

• Gráficos: Broadcom VideoCore VI, compatible con OpenGL ES 3.0 y decodificación de video 4K.

• Conectividad y Red: Gigabit Ethernet real, Wi-Fi 802.11ac de doble banda (2.4/5.0 GHz) y Bluetooth 5.0.

• Puertos Multimedia: 2 puertos USB 3.0, 2 puertos USB 2.0 y 2 salidas micro-HDMI (soporta doble pantalla 4K).

• Expansión: Cabezal GPIO estándar de 40 pines compatible con proyectos de hardware y electrónica.

🐍 Python: El Lenguaje del Futuro y del Hardware

💻 ¿Por qué Python en Raspberry Pi?

Python es el lenguaje oficial de la Fundación Raspberry Pi por su sintaxis limpia y directa. Permite a los desarrolladores conectar la lógica del software con el mundo físico de forma inmediata utilizando bibliotecas optimizadas para hardware.

🛠️ Librerías Clave para el Proyecto

Para exprimir al máximo las capacidades de la placa, Python cuenta con ecosistemas muy potentes:

  • RPi.GPIO / gpiozero: Control absoluto de los pines físicos para conectar sensores, LEDs y motores.
  • Flask / FastAPI: Creación de servidores web ligeros alojados directamente en la placa.
  • OpenCV: Procesamiento de imágenes en tiempo real y visión artificial con cámaras USB o de la Pi.

💡 Ejemplo Práctico: Control de Pines GPIO

Este fragmento muestra la estructura básica en Python para configurar un pin y encender un componente conectado a la placa:

import RPi.GPIO as GPIO import time # Configuración inicial del modo de pines GPIO.setmode(GPIO.BCM) GPIO.setup(18, GPIO.OUT) # Pin 18 configurado como salida def activar_componente(): print("Enviando señal eléctrica al pin 18...") GPIO.output(18, GPIO.HIGH) time.sleep(2) GPIO.output(18, GPIO.LOW) print("Proceso finalizado con éxito.") try: activar_componente() finally: GPIO.cleanup() # Limpiar los pines al terminar
